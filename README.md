# 🕵️ Spy Game — Шпион / Кто я?

Офлайн-игра для компании на одном телефоне. Один файл `index.html`, без сборки и зависимостей — открывается в браузере или как Telegram Mini App.

## Как играть
1. Один раз добавьте игроков (от 3 до 8) — список сохраняется и никуда не пропадает между раундами и перезапусками приложения.
2. Выберите тему слов (Brawl Stars, Clash Royale, страны, города, животные, фильмы, профессии, еда, спорт).
3. Выберите режим:
   - **Классический** — один шпион не знает слова.
   - **Два шпиона** — шпионов двое.
   - **Хаос** — у каждого своё уникальное слово, шпион без слова.
   - **Детектив** — один игрок знает слово и точно не шпион.
   - **Кто я?** — у всех одно слово, у одного другое, и он сам не знает, что отличается.
4. Передавайте телефон по кругу — каждый переворачивает карточку и смотрит свою роль.
5. Обсуждайте свободно, без таймера, затем голосуйте, кого подозреваете.
6. Очки за раунд сохраняются в общую таблицу лидеров (кнопка 🏆 на главном экране).
7. После раунда: «Ещё раунд» — сыграть заново с теми же игроками/темой/режимом; «Другая тема/режим» — сменить настройки, не трогая список игроков; «Изменить игроков» — добавить/убрать людей.

## Технически
- Один HTML-файл: разметка, стили и логика внутри `index.html`, без сборки.
- Интеграция с Telegram Mini App: `WebApp.ready/expand`, тактильная отдача (`HapticFeedback`), цвета шапки/фона.
- Прогресс и счёт хранятся в `localStorage` (таблица лидеров, защита от повторов одинаковых слов подряд).
- Работает и как обычная веб-страница вне Telegram.

## Ввод игроков
Экран игроков сразу показывает 3 плашки с полем для имени. Под последней — плашка с «+»: нажал — появилась ещё одна пустая плашка под именем, вплоть до 8. У плашек с 4-й и дальше есть крестик, чтобы убрать лишнюю. Кнопка «Далее» активна, только когда все плашки заполнены.

## Что изменилось по сравнению с первой версией
- Исправлены переносы строк в подсказке детектива.
- Добавлена защита от нехватки слов в маленьких темах при большом числе игроков.
- Добавлены кнопки «назад» на экранах темы/режима.
- Расширены все словари тем (30–52 слова вместо 8–50), добавлены темы «Еда» и «Спорт».
- Слова не повторяются подряд в рамках одной темы.
- Игроки вводятся один раз в самом начале и сохраняются в `localStorage` — не нужно вбивать имена перед каждым раундом.
- Добавлено голосование «кто шпион» и подсчёт очков; таймер обсуждения убран по просьбе — обсуждение теперь без ограничения по времени.
- Таблица лидеров, сохраняющаяся между партиями.
- Увеличены все интерактивные кнопки для удобного нажатия на телефоне.
- Улучшена доступность (видимый фокус, `aria`-атрибуты, поддержка `prefers-reduced-motion`).
- Favicon, meta-описание и Open Graph теги.
- Экран игроков переделан на плашки-слоты (см. раздел «Ввод игроков» выше) вместо строки ввода + списка.
- Убрано английское название «Spy Game» из интерфейса и заголовка страницы — оставлен только «Шпион», кроме исходных названий тем (Brawl Stars, Clash Royale).
- Карточка роли теперь крутится в одну сторону (по часовой) и при открытии, и при закрытии, а не отматывается назад.
- В голосовании клик по новому игроку сразу переключает выбор — не нужно сначала снимать старый.
- Плотная компоновка под маленькие экраны: карточка, кнопки и плашки игроков уменьшены так, чтобы экран с 8 игроками помещался на обычном телефоне без прокрутки.
- «Сбросить счёт» и «Очистить всех» переведены на собственное модальное окно подтверждения вместо системного `confirm()` — в Telegram Mini App системные диалоги часто не показываются и кнопки выглядели нерабочими.
- Стрелки «назад»/«далее» между ролями объединены в один симметричный ряд (круглая стрелка ← слева, кнопка → справа), вместо того чтобы кнопка «назад» появлялась и исчезала снизу.
